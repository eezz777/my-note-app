# 마이노트

구글드라이브에 저장하는 개인 마크다운 노트 앱(PWA). 옵시디언 호환 마크다운 + UpNote 느낌의 화면.

- 앱: 정적 웹앱(서버 없음). GitHub Pages에 올려 PC·안드로이드 Chrome에서 설치해 사용
- 데이터: 내 구글드라이브의 일반 폴더에 `.md` 파일로 저장(앱 서버·제3자 서버로 보내지 않음)
- 오프라인: 앱과 노트 모두 오프라인에서 열림(서비스 워커 + IndexedDB)
- 분석/추적 코드 없음. 외부 CDN 없음(구글 로그인 스크립트만 로그인할 때 구글에서 받음).

> 처음 쓰는 순서: **1. 내 PC에서 실행**(데모 모드로 둘러보기) → **3. 구글드라이브 연결 준비** → **2. GitHub Pages 배포** → **4. 앱 설치** → **5. 실기기 점검**

### 구글드라이브 동기화
- 노트는 드라이브 `MyNotes` 폴더에 폴더 구조 그대로 `.md` 파일로 저장됩니다. 첨부는 `MyNotes/_attachments`, 즐겨찾기·포인트 색 같은 공통 설정은 `MyNotes/.mynotes/settings.json`.
- 이 기기에도 사본이 있어 **오프라인에서도 읽고 쓸 수 있고**, 연결되면 자동으로 올립니다. 앱을 껐다 켜도 올릴 변경은 남아 있습니다.
- 동기화 시점: 앱을 열 때, 다시 화면에 돌아올 때, 인터넷이 다시 연결될 때, 1분마다, 고친 뒤 3초 후, 사이드바 아래 ⟳ 버튼(지금 동기화).
- 상태 표시(사이드바 맨 아래): 동기화됨 / 올릴 변경 N개 / 동기화 중 / 오프라인 / 오류 / 로그인 필요.
- **충돌**: 두 기기에서 같은 노트를 고치면 먼저 올라간 쪽이 원본이 되고, 늦은 쪽 내용은 `노트이름 (충돌 2026-11-18 14시 05분)` 노트로 따로 저장됩니다(지우지 않음). 알림의 **비교**를 누르면 바뀐 줄을 나란히 보고 "원본 유지 / 사본으로 바꾸기 / 직접 합치기 / 둘 다 유지"를 고릅니다. (윈도우·옵시디언에서 쓸 수 없는 `:` 대신 "시 분"으로 표기합니다.)
- **휴지통**: 지우면 드라이브 휴지통으로 갑니다(복원 가능). 앱 휴지통에서 "영구 삭제"하면 드라이브에서도 지워집니다.
- **이전 버전**: 노트 메뉴(⋮) → 이전 버전. 드라이브 버전 기록(보통 30일·최대 100개)을 보고, 지금과 비교하고, 되돌릴 수 있습니다.
- **로그인 만료**: 구글 로그인은 약 1시간마다 갱신이 필요합니다. 만료되면 화면 위에 "다시 로그인" 안내가 뜨고, 그동안 쓴 내용은 이 기기에 안전하게 보관되었다가 다시 로그인하면 올라갑니다.
- **가져오기·백업**(설정): `.md` 여러 개, ZIP, 옵시디언 볼트 ZIP 가져오기(링크·이미지 경로 자동 정리, `.obsidian` 설정은 건너뜀). 전체 백업 ZIP 내려받기(폴더 구조 + `_attachments`).
- 앱은 `drive.file` 권한만 쓰므로 드라이브 웹에서 `MyNotes`에 직접 넣은 파일은 앱에 보이지 않습니다. 기존 노트는 **가져오기**로 넣어 주세요.

### 터치·여러 개 선택
- 폰: 노트 카드를 **길게 누르면 선택 모드**(여러 개 골라 즐겨찾기·이동·휴지통), **왼쪽으로 밀면 휴지통**(실행 취소 가능), **오른쪽으로 밀면 즐겨찾기**.
- PC: Ctrl/⌘+클릭으로 여러 개 선택, Shift+클릭으로 범위 선택, 선택한 노트를 폴더로 끌어다 놓으면 한 번에 이동, Esc로 선택 해제. Ctrl+\ 로 사이드바 접기.

### 검색
- **전체 검색**(Ctrl+Shift+F, 사이드바·목록의 돋보기): 제목·본문·태그를 한 번에 찾습니다. 한글은 일부만 써도 찾고, 여러 단어는 모두 포함된 노트만 나옵니다.
  - `tag:업무` 태그(하위 태그 포함), `folder:프로젝트` 폴더, `title:회의` 제목, `"주간 보고"` 구절, `-취소` 제외
  - 결과를 누르면 처음 찾은 줄로 이동합니다. 뒤로가기로 검색 결과에 돌아옵니다.
- **빠른 열기**(Ctrl+P): 노트 이름으로 바로 열기. 글자를 건너뛰어도 되고 초성(`ㅁㅋㄷ` → 마크다운)도 됩니다. 없으면 그 이름으로 새 노트를 만들 수 있습니다.
- 그 밖의 단축키: Ctrl+Alt+N 새 노트
- 검색은 이 기기의 로컬 캐시에서 별도 스레드(워커)로 처리해 오프라인에서도 빠릅니다(노트 5,000개 약 5MB 기준 수십 ms).

### 노트 링크
- `[[노트]]`, `[[노트|보이는 글자]]`, `[[노트#제목]]`, `[[노트#^문단ID]]`, 같은 노트 안 `[[#제목]]`. 같은 이름의 노트가 여러 폴더에 있으면 `[[폴더/노트]]`.
- `[[` 를 치면 노트 이름, 이어서 `#` 은 제목, `#^` 는 문단 목록이 나옵니다. ID가 없는 문단을 고르면 그 문단 끝에 `^abc123` 이 자동으로 붙습니다.
- 노트 메뉴(⋮) → "커서 문단 링크 복사"는 커서가 있는 문단에 ID를 붙이고 `[[노트#^ID]]` 를 복사합니다.
- 링크에 마우스를 올리거나(PC) 길게 누르면(폰) 미리보기가 뜹니다. `![[노트]]`, `![[노트#제목]]` 은 본문에 끼워 넣어 보여 줍니다(3단계 깊이까지).
- 노트 이름 변경·이동, 폴더 이름 변경·이동 시 그 노트를 가리키는 모든 `[[링크]]` 가 자동으로 고쳐집니다(코드 블록 안은 그대로).
- 편집기 위의 패널 버튼: 목차, 백링크(이 노트를 가리키는 노트와 문장), 링크 안 된 언급 찾기(눌러서 `[[링크]]` 로 바꾸기), 그래프(아래).

### 그래프
- 사이드바 **그래프**: 모든 노트를 점으로, `[[링크]]` 를 선으로 보여 줍니다. 연결이 많은 노트일수록 점이 큽니다.
- 노트 패널(편집기 위 패널 버튼) → **그래프** 탭: 지금 노트와 연결된 노트만 보여 줍니다. "연결 단계 1 / 2"로 얼마나 멀리까지 볼지 고릅니다.
- 조작: 점을 누르면 그 노트가 열립니다. 빈 곳을 끌면 이동, 마우스 휠·두 손가락으로 확대/축소, 점을 끌어 자리를 옮길 수 있습니다. 오른쪽 아래 버튼: 확대 · 축소 · 화면에 맞추기.
- PC에서 점에 마우스를 올리면 그 노트와 이웃만 강조되고 이름이 보입니다. 점이 많으면 확대할수록 이름이 더 보입니다.
- 위의 **태그** 를 켜면 태그도 점(점선으로 연결)으로, **없는 노트** 를 켜면 링크만 있고 아직 만들지 않은 노트도 빈 점으로 보입니다. 태그 점을 누르면 그 태그의 노트 목록이 열립니다.

### 태그
- 본문 어디서든 `#태그`, 중첩 태그 `#업무/회의`, frontmatter `tags: [a, b]` 를 인식합니다. 코드 블록·인라인 코드·수식 안의 `#`, `# 제목`, `#123`(숫자만), URL의 `#` 은 태그가 아닙니다.
- `#` 을 입력하면 기존 태그 자동완성(한글 조합 중에는 Enter가 조합 확정에 쓰임).
- 사이드바 태그를 누르면 그 태그(하위 태그 포함) 노트만 보입니다. 목록 위 `＋ 태그` 또는 사이드바에서 Ctrl+클릭으로 태그를 더하고 "모두 포함(AND) / 하나라도(OR)" 를 고릅니다.
- 태그 메뉴(⋮)의 "이름 변경"으로 모든 노트의 태그를 한 번에 바꿉니다(하위 태그도 함께).

### 첨부파일
- 넣는 방법: 툴바의 이미지·PDF·클립 버튼, 붙여넣기(캡처 이미지), 파일 끌어다 놓기. 폰에서는 이미지 버튼에서 "사진 찍기"를 고를 수 있습니다.
- 파일은 노트 루트의 `_attachments/` 폴더에 저장되고, 노트에는 `![[파일명.png]]`(이미지·PDF·오디오·비디오) 또는 `[[파일명.docx]]`(그 밖의 파일)로 들어갑니다.
- 이미지 크기: `![[사진.png|300]]` (너비), `![[사진.png|300x200]]` (너비×높이)
- PDF 특정 페이지: `![[문서.pdf#page=3]]`
- 큰 이미지(긴 변 2560px 또는 1.5MB 초과)는 넣을 때 2048px로 줄일지 묻습니다. 설정에서 "자동으로 줄이기/원본 유지"로 바꿀 수 있습니다.

## 1. 내 PC에서 실행하기

필요한 것: [Node.js](https://nodejs.org/) 20 이상(LTS 권장)

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 열고 **데모 모드로 둘러보기**를 누릅니다.

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm test` | 자동 테스트 |
| `npm run check` | 타입 검사 |
| `npm run build` | 배포용 빌드(`dist/`) |
| `npm run icons` | `public/favicon.svg`로 앱 아이콘 다시 만들기 |

## 2. GitHub Pages에 배포하기

### 2-1. Git 설치 (처음 한 번)
1. https://git-scm.com/download/win 에서 Windows용 Git을 받아 설치합니다(설치 옵션은 기본값 그대로).
2. 새 터미널을 열고 이름과 이메일을 등록합니다.
   ```bash
   git config --global user.name "내 이름"
   git config --global user.email "내 GitHub 이메일"
   ```

### 2-2. GitHub 저장소 만들기
1. https://github.com 에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name: 예) `my-note-app` (이 이름이 주소의 일부가 됩니다)
3. **Public** 선택 (무료 계정의 GitHub Pages는 공개 저장소에서만 동작합니다. 공개되는 것은 앱 코드뿐이고 노트는 내 드라이브에만 있습니다)
4. README 추가 등은 체크하지 않고 **Create repository**

### 2-3. 코드 올리기
프로젝트 폴더에서 아래를 차례로 실행합니다(`<사용자>`는 내 GitHub 아이디).
```bash
git init -b main
git add .
git commit -m "첫 커밋"
git remote add origin https://github.com/<사용자>/my-note-app.git
git push -u origin main
```
처음 push할 때 GitHub 로그인 창이 뜨면 로그인합니다.

### 2-4. Pages 켜기
1. 저장소 → **Settings** → 왼쪽 **Pages**
2. **Build and deployment → Source** 를 **GitHub Actions** 로 선택
3. 저장소 **Actions** 탭에서 `Deploy to GitHub Pages` 작업이 초록색 체크가 될 때까지 기다립니다(1~2분). 실패하면 다시 실행(Re-run)합니다.
4. 앱 주소: `https://<사용자>.github.io/my-note-app/`

이후에는 `git push` 할 때마다 자동으로 테스트 → 빌드 → 배포됩니다.

## 3. 구글드라이브 연결 준비 (Google Cloud 설정, 처음 한 번)

앱이 내 구글드라이브에 노트를 저장하려면 "이 앱이 드라이브를 써도 된다"는 **클라이언트 ID**가 필요합니다. 무료이며 서버나 비밀키는 필요 없습니다. 아래 순서대로 하면 10분 정도 걸립니다. (구글 화면 메뉴 이름은 가끔 바뀝니다. 비슷한 이름을 찾으면 됩니다.)

### 3-1. 프로젝트 만들기
1. https://console.cloud.google.com 에 노트를 저장할 구글 계정으로 로그인합니다. (처음이면 약관 동의)
2. 화면 위쪽의 **프로젝트 선택** 상자 → **새 프로젝트**
3. 프로젝트 이름: `MyNotes` (아무 이름이나 됨) → **만들기** → 만들어지면 그 프로젝트를 선택합니다.

### 3-2. Google Drive API 켜기
1. 왼쪽 메뉴(☰) → **API 및 서비스** → **라이브러리**
2. 검색창에 `Google Drive API` → 결과 클릭 → **사용**

### 3-3. OAuth 동의 화면(Google 인증 플랫폼) 설정
1. 왼쪽 메뉴(☰) → **API 및 서비스** → **OAuth 동의 화면** (또는 **Google 인증 플랫폼**) → **시작하기**
2. **앱 정보**: 앱 이름 `마이노트`, 사용자 지원 이메일은 내 이메일 → 다음
3. **대상(Audience)**: **외부(External)** → 다음
4. **연락처 정보**: 내 이메일 → 다음 → 정책 동의 체크 → **만들기**
5. 왼쪽 **데이터 액세스**(또는 범위) → **범위 추가 또는 삭제** → 목록 아래 "직접 범위 추가"에 아래 주소를 넣고 **표에 추가** → **업데이트** → **저장**
   ```
   https://www.googleapis.com/auth/drive.file
   ```
   이 범위는 "이 앱이 만든 파일만 접근"하는 가장 좁은 권한이라 구글 심사가 필요 없습니다.
6. 왼쪽 **대상(Audience)** → 게시 상태가 **테스트 중**이면 **앱 게시** → **확인**을 눌러 **프로덕션**으로 바꿉니다.
   - **앱 게시** 버튼이 회색이면 **브랜딩** 페이지의 필수 항목이 비어 있는 것입니다. 채우거나, 아래처럼 테스트 사용자로 쓰면 됩니다.
   - 테스트 상태로 둘 때는 같은 화면의 **테스트 사용자 → Add users**에 로그인할 구글 계정을 꼭 추가하세요. 빠지면 `403 access_denied`가 납니다.
   - 로고는 넣지 마세요(로고를 넣으면 구글 심사가 필요해질 수 있습니다).

### 3-4. 클라이언트 ID 만들기
1. 왼쪽 **클라이언트**(또는 **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**)
2. **애플리케이션 유형**: **웹 애플리케이션**, 이름: `마이노트 웹`
3. **승인된 JavaScript 원본**에 아래를 하나씩 추가합니다(주소 끝에 `/`나 경로를 붙이지 않습니다).
   ```
   http://localhost:5173
   http://localhost
   https://<사용자>.github.io
   ```
   `<사용자>`는 내 GitHub 아이디입니다. 저장소 이름(`/my-note-app`)은 넣지 않습니다.
4. **승인된 리디렉션 URI**에 아래를 추가합니다(이번에는 끝에 `/`까지 정확히). 로그인 창(팝업)이 안 뜨는 PC에서 쓰는 "페이지 이동으로 로그인"에 필요합니다. → **만들기**
   ```
   https://<사용자>.github.io/my-note-app/
   http://localhost:5173/
   ```
5. 나타난 **클라이언트 ID**(`숫자-문자.apps.googleusercontent.com`)를 복사해 둡니다. 클라이언트 보안 비밀번호(secret)는 쓰지 않습니다.

### 3-5. 앱에 클라이언트 ID 넣기
- 앱 시작 화면의 **구글드라이브 연결**을 누르면 클라이언트 ID를 묻습니다. 붙여넣고 **연결** → 구글 로그인 창에서 계정 선택 → **허용**.
- 폰에서 매번 붙여넣기 싫다면, GitHub 저장소 → **Settings → Secrets and variables → Actions → Variables 탭 → New repository variable**: 이름 `GOOGLE_CLIENT_ID`, 값은 클라이언트 ID. 다음 배포부터 자동으로 들어갑니다. (클라이언트 ID는 비밀값이 아니라 공개되어도 괜찮습니다.)
- 드라이브에 `MyNotes` 폴더가 생기고, 그 안에 폴더와 `.md` 노트, `_attachments`(첨부), `.mynotes`(앱 설정)가 저장됩니다.

> **"이 앱은 Google에서 확인하지 않았습니다"** 화면이 나오면: **고급** → **마이노트(으)로 이동**을 누르면 됩니다. 내가 만든 내 앱이므로 안전합니다.

#### 연결 오류가 날 때
| 오류 문구 | 원인과 해결 |
|---|---|
| `401 invalid_client` (OAuth client was not found) | 클라이언트 ID가 틀렸습니다. 콘솔 **클라이언트**에서 복사 아이콘으로 다시 복사해, 입력란을 비우고 붙여넣으세요. 보안 비밀번호(`GOCSPX-…`)나 프로젝트 ID가 아닌지 확인하세요. |
| `403 access_denied` (테스트 중인 앱) | 로그인한 계정이 테스트 사용자에 없습니다. 3-3의 6번처럼 추가하거나 앱을 게시하세요. |
| `origin_mismatch` / 허용되지 않은 출처 | 3-4의 **승인된 JavaScript 원본**에 지금 주소(예: `http://localhost:5173`)가 없습니다. 추가 후 몇 분 기다리세요. |
| `Google Drive API has not been used in project … or it is disabled` | 3-2의 **Google Drive API 사용**이 빠졌습니다. 켠 뒤 1~5분 기다렸다 다시 로그인하세요. |
| 로그인 창이 안 열림 / 바로 "로그인 창이 닫혔습니다" | 확장 프로그램이나 팝업 설정이 로그인 창을 막는 경우입니다. 로그인 버튼 아래 **"로그인 창이 안 뜨나요? 페이지 이동으로 로그인"** 을 누르세요. 한 번 쓰면 그 기기에서는 계속 이 방식으로 로그인합니다. |
| `redirect_uri_mismatch` | 3-4의 **승인된 리디렉션 URI**에 앱 주소(끝의 `/` 포함)가 없습니다. 추가 후 몇 분 기다리세요. |

## 4. 앱 설치하기

- **PC (Chrome/Edge)**: 앱 주소를 열고 주소창 오른쪽의 설치 아이콘(모니터+화살표) → 설치
- **안드로이드 (Chrome)**: 앱 주소를 열고 오른쪽 위 ⋮ → **앱 설치** (또는 **홈 화면에 추가**)

새 버전이 배포되면 앱 하단에 "새 버전이 있습니다 · 업데이트" 알림이 뜹니다. 편집 중 갑자기 새로고침되지 않도록 직접 눌러서 적용합니다.

## 5. 실기기 점검 (배포 후 한 번)

PC와 폰에서 아래를 차례로 해 보면 모든 기능이 실제 환경에서 동작하는지 확인할 수 있습니다.

1. **PC Chrome**에서 앱 주소 열기 → 구글드라이브 연결 → 설치
2. PC에서 폴더와 노트를 만들고, 이미지 하나를 붙여넣기 → 사이드바 아래가 "동기화됨"이 되는지 확인
3. **안드로이드 Chrome**에서 같은 주소 열기 → 같은 계정으로 연결 → ⋮ → 앱 설치
4. 폰에서 PC에서 만든 노트와 이미지가 보이는지 확인
5. 폰에서 노트를 고치고 PC 앱으로 돌아가면(창을 클릭하면) 바로 반영되는지 확인
6. 폰을 **비행기 모드**로 바꾸고 노트를 고친 뒤 앱을 닫기 → 비행기 모드를 끄고 앱 열기 → 올라가는지 확인
7. 두 기기에서 같은 노트를 동시에 고쳐 보기 → "(충돌 …)" 사본과 **비교** 화면 확인
8. 폰에서 카드 길게 누르기(선택), 왼쪽/오른쪽으로 밀기, 뒤로가기 버튼, 그래프 두 손가락 확대
9. 노트 메뉴(⋮) → 이전 버전 → 되돌리기

문제가 생기면 화면을 캡처하고, PC라면 F12 → Console 탭의 빨간 오류도 함께 남겨 두면 원인을 찾기 쉽습니다.
